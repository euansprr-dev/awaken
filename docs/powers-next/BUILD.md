## M1. The arm (module `anims`, light in `powers.client.fx`)

**Clip schema 2** (`anims.FpClipSet`, files may be schema 1 or 2):
- `"arm": true` on a fists clip: each fist key's three spare values are the forearm's pitch and yaw (degrees, view space: 0, 0 points
  straight ahead; yaw + to the right, pitch + up) and the wrist's roll. The elbow is `fist - dir * 0.6`. Without it: today's arm.
- `"mainMoves": true` / `"offMoves": true`: that track is offsets (moves what the hand holds) while the other is fists. This is the
  left-hand cast: off = fist keys, main = the weapon lowered into a guard.
- `"ease": true` with `"stow": true`: the put-away eases (2.5 ticks down, 3 back) instead of popping.
- `"light"`: `[[tick, chargeMain, heatMain, chargeOff, heatOff, ease], ...]`: the arm light, keyed with the motion.

**View** (`core.api.FirstPerson.View`): `armMain/armOff` (pitch, yaw, roll, weight), `lightMain/lightOff` (charge, heat, weight),
`stowEase`. `Hands.compose` fills them from clips; a clip's main move also moves a weapon's grip (`gripMain' = t + R * grip`).

**Drawing** (`WorldBody.drawFist`): root from the keyed direction; front = up squared to the arm, turned by the roll (toward the
viewer when the arm stands straight up); an upper arm from under the frame `(side * 0.52, -1.30, -0.30)` to the elbow, a shade
darker, drawn only when the elbow is above `y = -0.95`. After each fist or grip: `ArmLayers.draw(...)` with the stack in the arm
cube's space (x across in px/16 from x0 to x1, y -2/16 shoulder end to 10/16 hand end, z -2/16 to 2/16).

**The light** (`powers.client.fx.ArmLight`, an `ArmLayers.Layer`): procedural pixel patterns on the skin's own grid (4 x 12 a
face, 3 wide on slim arms), one per family, animated toward the fist, seeded by the power, level 5 adds the awakened motif.
Cells are `debugQuads` (plain colour, unlit: reads as emissive) 0.004 above the skin; a halo is an inflated box in `lightning`
(additive). Sources: the clip's light track when it has one; else a default from the cast's age against its release tick, so
every profiled power lights at once; and auras for powers that sit on you (Barrier, Mend, Brace, Nanite Skin, Cloak, Bulwark,
Overload's buff), which hold the hands as fists at rest so there is an arm to light.

## M2. Voice

- **Data**: `assets/awaken/power_voices.json`, generated by `tools/art/specs/power_voices.py` (one table for all powers; checks every
  recording against the game's asset index; refuses tonal sources). `voices.<power>.<beat>` = one or two layer sets; a layer =
  `[event, tick, volume, pitch, jitter, cut]`. Beats: `gather, peak, release, travel, impact, tail, echo, hold, end, level5`.
- **Events**: layer events are `awaken:voice.<name>` in `merge/powers/assets/awaken/sounds.json`, each listing the game's takes by
  name. Not registered: the client plays them by id (`SimpleSoundInstance`), so no registry or network change.
- **Wire**: `FxKind.VOICE`: `power` = the power, `aux` = beat, `scale` = intensity, `colour` = the classic sound's registry id
  (so one event serves both settings), `seed`, position, `FOLLOW`.
- **Server**: `Cast.voice(beat, classic, volume, pitch)` and `voice(at, beat, ...)`. Every `c.sound(...)` in the catalogs becomes a
  `c.voice(...)` naming its beat and keeping the old sound as the classic.
- **Client** (`powers.client.fx.PowerVoice`): picks the set by seed, schedules layers with `SoundManager.playDelayed`, cuts
  flagged layers on a let-go, adds the struck block's own break sound on `impact` (`surface: true`), ducks the bed before the
  biggest hits, at most 12 voices a cast, two layers beyond 24 blocks. Setting `powerVoice`: New (default) or Classic.

## M3. Takes and ways

- **Way**: 0 standing, 1 at a sprint or slide, 2 in the air. The hands decide at the press (`Ways.of`); it rides the cast payload
  (`keys` bits 4-5); the server keeps it when plausible (in the air within 3 ticks, sprinting within 5), else standing.
  `Cast.way`; events carry it in flag bits 12-13.
- **Take**: 0-2 from a per-power counter on the client, payload bits 6-7, event bits 14-15, so everyone sees the same one.
- **Clip pick** (`CastPick`): `fp_p_<power>[__run|__air][_t2|_t3]`, falling back toward the base; the same names in third person.
  A way's clips release on the base's tick (the generator asserts it).
- **Press buffer**: a power key pressed in the last 3 ticks of its cooldown, or during another power's wind-up, is kept and
  fires when it can. Recovery after the release never blocks an attack.

## M4. Every cast

`tools/art/specs/fp_casts2.py`: authored with elbow points (converted to angles), light tracks, left-hand casts, takes by small
changes of path and timing, ways for the physical powers. Rules checked by the generator: poses in the safe frame, no hand in the
middle fifth for more than 2 ticks, anticipation before a strike, hands never start together, overshoot and settle, no two
powers alike. Camera: `CastFeel` moments take parameters (`kick`, `dip`, `fov`, `roll`, `hold`) so each power has its own.
