# Audio tour (docs/modules/audio.md). Builders can't hear the client, so this tour is checked in three ways:
#  1. the log: every cue writes "[audio] cue <id> started" (or why it was skipped), grep logs for "[audio]";
#  2. the shots: the Now Playing toast names each cue when it starts (if Options > Music & Sounds > "Show music toast"
#     is on), the subtitles (Options > Accessibility > Show Subtitles) name every sound;
#  3. listening, if the owner wants to: run it with the volume up.
# Cues go through vanilla's music manager: one waits while a song plays, so `cue` here forces them one by one with
# enough time between for each to finish (the longest is 34 s).
world audio creative 4242
waitworld
gui 0
cmd time set 6000
cmd time pause
look 0 5
wait 60
# the awakening: the System's theme (and the level-up sounds)
cmd awaken admin awaken
wait 140

wait 700
cmd awaken audio cue beast
wait 80
shot 02_beast_cue
wait 360
cmd awaken audio cue gate_forming
wait 80
shot 03_gate_forming_cue
wait 360
cmd awaken audio cue gate_broke
wait 80
shot 04_gate_broke_cue
wait 420
cmd awaken audio cue shrine
wait 80
shot 05_shrine_cue
wait 440
cmd awaken audio cue lair
wait 80
shot 06_lair_cue
wait 360
cmd awaken audio cue rank_up
wait 100
shot 07_rank_up_cue
wait 500
