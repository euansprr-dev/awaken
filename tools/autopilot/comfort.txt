# Comfort tour (Awakened Pack stage 5, docs/plan-pack.html): JEI, Jade and Xaero's World Map with Awaken's plugins.
#   PACK=comfort tools/autopilot.sh tools/autopilot/comfort.txt
# Survival, so the spoiler guard is on (creative sees everything). Shots:
#   01-02  JEI beside the inventory on a fresh player: Awaken's items hidden, the guard's count in the log
#   03-04  after picking things up: they (and the recipes they teach) appear
#   05-13  each Awaken JEI category, in the System's glass
#   14-20  Jade on a gate, machines, a broken machine, a creature, the Hearth Anchor and a townsperson
#   21-22  Xaero's World Map in the overworld and inside a gate
# Read the log for [compat] lines (guard counts, plugin start) and for errors from any comfort mod.

cmd weather clear 1000000
cmd time set 6000
