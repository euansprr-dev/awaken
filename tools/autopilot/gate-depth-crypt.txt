# Gate depth stage 3 (SPEC 38.14): the Bell Crypt's own worlds (the hall, the passages, the shaft, the field) worn at content version 7
# beside version 6, on the depth test's plan: on floor 1 of each, the biggest place and the second, from just inside where
# you walk in, a block over the ground.
#
# Commands it relies on (game master):
#   /awaken gate open <rank> <theme> world <version> <world id>   every floor in that world, on the depth test's plan
#   /awaken gate interior enter                                    into the gate opened last (else the newest)
#   /awaken gate interior goto <place|place2>                      a world floor's biggest place, or its second
#   /awaken gate leave, /awaken gate hop
world autopilot_gate_depth creative 20261029
waitworld
gui 0
cmd weather clear 1000000
cmd gamerule awaken:fauna_spawning false
cmd time set 6000
cmd time pause
cmd awaken admin awaken
wait 200
cmd awaken powers starter 1
wait 20
screen close
cmd difficulty peaceful
cmd gamerule send_command_feedback false
hud off
# away from Carillon first: gates never form in its reserve, and the first hop (no gates yet) stays close; on CI the
# land out there takes a while to make, so wait for it before the first gate looks for dry ground
cmd tp @s 6000 200 6000
wait 600

wait 160
