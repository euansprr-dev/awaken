# Gate depth (SPEC 38.14): the Hive's places before (content version 6) and after (version 7, shaped ground), the same
# floors both times (the depth test's plan): on floor 1 of the Comb, the Brood Hall and the Swarm, the biggest place and
# the second, from just inside where you walk in, a block over the ground.
#
# Commands it relies on (game master):
#   /awaken gate open <rank> <theme> world <version> <world id>   every floor in that world, on the depth test's plan
#   /awaken gate interior enter                                    into the newest standing gate
#   /awaken gate interior goto <place|place2>                      a world floor's biggest place, or its second
#   /awaken gate leave, /awaken gate hop

cmd gamerule awaken:fauna_spawning false

cmd awaken admin awaken
