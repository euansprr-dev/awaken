# Placement (SPEC 38.16, content version 9): six gate worlds where things hung in the air, before (version 8) and after
# (version 9), on the depth test's plan. Each pair is shot from the same spot: hovering where the floor's biggest thing
# not held up at version 8 is in view (goto float works it out from the version 8 floor whichever version you're in).
# The Stacks' rock lumps and litter on half steps, the Cloisters' prayer flags, the Rooftops' strings of lights, the
# Dark Steps' flights into the dark, the Open Chasm's rock and the Upside-Down house's furniture.
#
# Commands it relies on (game master):
#   /awaken gate open <rank> <theme> world <version> <world id>   every floor in that world, on the depth test's plan
#   /awaken gate interior enter                                    into the gate opened last (else the newest)
#   /awaken gate interior goto float                               where version 8's biggest float on this floor shows
#   /awaken gate leave, /awaken gate hop
world autopilot_gate_placement creative 20261103
waitworld
gui 0
cmd weather clear 1000000
cmd gamerule awaken:fauna_spawning false
cmd time set 6000
cmd time pause
cmd awaken admin awaken
wait 200
cmd awaken powers starter 1
wait 20

cmd difficulty peaceful
cmd gamerule send_command_feedback false
hud off
# away from Carillon first; on CI the land out there takes a while to make
