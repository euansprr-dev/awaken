# Placement (SPEC 38.16, content version 9): five gate worlds where things hung in the air, before (version 8) and
# after (version 9), on the depth test's plan, from where you walk into each floor's biggest place. Floating rock in a
# cave roof, the Festival's great lantern, the Cloisters' prayer flags, the Bell Shaft's bells and the Upside-Down
# house's furniture.
#
# Commands it relies on (game master):
#   /awaken gate open <rank> <theme> world <version> <world id>   every floor in that world, on the depth test's plan
#   /awaken gate interior enter                                    into the gate opened last (else the newest)
#   /awaken gate interior goto <place|place2>                      a world floor's biggest place, or its second
#   /awaken gate leave, /awaken gate hop
world autopilot_gate_placement creative 20261103
