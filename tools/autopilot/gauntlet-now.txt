# The Leaper's Gauntlet as it is today (SPEC §17.10, §63.2), in first person with the HUD on, the way Euan met it on
# 11 Nov: for the plan docs/leapers-gauntlet/PLAN.md, not a test of anything. The gate opening (its panel), the gate in
# the world, the antechamber, the course from its doorway and from the start, then the edge as he ran it: a sprint off
# the run-up with no second jump, so the leap is given and the pit takes him half a second later (a shot every few
