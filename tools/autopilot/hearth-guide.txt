# The Hearth guide (hearth/guide): root an Anchor (the "Home exists" toast, the Now line "Use the Anchor for a guide"),
# use it ("Your Hearth": the facts, Oren's offer, the room cards with checklists, icons and the Meditation Mat recipe),
# the radius ring in the world, Oren's cottage card, Y, the cottage rising row by row, outside (front, chimney side, by
# night) and inside (the bed, the mat, the lanterns), the "Sanctuary recognised" toast, then the screen again with the
# Sanctuary built ("Oren built this one"), at GUI scale 0 (the owner's) and 2.
# Run by the integrator: tools/autopilot.sh hearth-guide (builders never run a client).
world autopilot_hearth_guide creative 4242
waitworld
gui 0
cmd weather clear 100000
cmd time set 6000
cmd gamerule awaken:fauna_spawning false
cmd awaken admin awaken

cmd awaken powers starter 1

wait 10

wait 50

cmd awaken hearth guide
wait 30

wait 10

gui 0

wait 10

wait 70

shot hearth_guide_05_cottage_rising

shot hearth_guide_06_sanctuary_recognised_toast
