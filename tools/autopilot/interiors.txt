# Interiors tour (docs/modules/gates.md "Interiors"): one gate of every theme, entered for real: the first room facing
# the way on, the floor's biggest set piece, the room before the Rest Shrine facing its blue door, the antechamber
# facing the arena, and the arena seen from its doors with the Lord on its lit medallion.
# Run by the integrator: tools/autopilot.sh interiors (builders never run a client).
#
# Commands it relies on (game master):
#   /awaken gate open <rank> <theme>     a gate of that theme 18-30 blocks away (forms in a few seconds; gates stand 96+ apart)
#   /awaken gate interior enter          walk into the newest standing gate (yours first)
#   /awaken gate interior goto <start|piece|small|shrine|ante|lord>
#                                        inside a gate: stand where that place reads best, facing it (ante and lord go to the
#                                        Lord's floor; stepping into the arena wakes the Lord)
#   /awaken gate leave                   out again, Satchel kept
#   /awaken gate hop                     to dry land 160+ blocks from every gate (between gates)
world autopilot_interiors creative 20261024
waitworld
gui 0
cmd weather clear 1000000
cmd gamerule awaken:fauna_spawning false
cmd time set 6000
cmd time pause
cmd awaken admin awaken
wait 200
cmd awaken powers starter 1
wait 20
screen close
cmd gamerule send_command_feedback false
