# ci knobs: PACK=comfort
# Survival first, so the spoiler guard is on. Shots:
#   01-02  a fresh player holding planks and logs: the Bell Frame's recipe unlocks, so JEI shows the frame and its recipe
#   03-10  everything discovered: JEI searches for things that were missing or folded into one (bells, power cores,
#          enchantment pages, flower boxes, binoculars, lode hearts, meals, the townsfolk's things)
#   11-    creative: every Awaken tab in turn (a long tab once more, scrolled down), JEI's list beside it
# Read the log for "[compat] JEI lists" (registered Awaken items JEI has no entry for, and those it lists in several
# kinds), "[compat] creative menu" (every tab, its page and its size) and "[core] creative tabs" (the check).
world autopilot_jeitabs survival 4242
waitworld
gui 0
window 1440 900
cmd weather clear 1000000
cmd time set 6000
cmd gamerule awaken:fauna_spawning false
cmd gamerule mob_griefing false
cmd awaken admin awaken
wait 100
cmd awaken powers starter 1
wait 20
screen close
cmd effect give @s minecraft:resistance infinite 4 true
cmd effect give @s minecraft:saturation infinite 1 true
info
cmd awaken core tabs
compat jei missing

# ---- the Bell Frame on a fresh player: its recipe unlocks from planks and logs, and that discovers it ----------------

cmd awaken compat discovered reset
wait 60
cmd give @s minecraft:oak_planks 8

wait 20

wait 10
shot jeitabs_01_bell_frame_fresh_player
compat jei recipes awaken:bell_frame
wait 20
shot jeitabs_02_bell_frame_recipe
