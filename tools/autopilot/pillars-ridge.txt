# A gate pillar behind a ridge (Euan, 29 Oct: "One of the gate beams is showing on top of the cliff here even tho the
# gate is behind it"). Render distance 6 (96 blocks): a pillar past 67 blocks used to be drawn pulled in to 67, so land
# between 67 blocks and the end of the chunks never hid it. This seed's first C gate forms at 1104 82 -1113 (gate 1 in
# the log); the camera stands east of it over open land, 200 and then 400 blocks off, looking west, and a stone wall
# rises 80 blocks in front of it to 8 blocks over the eye. The beam must show only above the wall, never across its
# face. (Far Sight's land, the other half of the fix, stays on the Mac: Far Sight is off here.)
# Run on GitHub's Mac runners:
#   tools/tour-ci.sh tools/autopilot/pillars-ridge.txt 1500 TECTONIC=awakened PACK=perf,world,horizon
# ci knobs: RD=6
world carillonM4b3a creative 20261024

cmd gamerule advance_time false
cmd weather clear 1000000
cmd awaken admin awaken
wait 200
cmd awaken powers starter 1
wait 20

cmd gamemode spectator
cmd time set 6000
cmd tp @s 1110 140 -1090
wait 100

wait 20

wait 20
cmd awaken gate open C
wait 200
cmd awaken gate list
