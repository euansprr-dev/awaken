# Gate pillars, our own soft light (Euan: vanilla's beacon beam read as "a weird boxed outline" over Carillon; then
# "the outline of the main light is still there and blocky": a pale slab with hard sides and a flat top at noon from a
# roof 100-200 blocks off). A C-rank gate (pale blue) opened just east of Carillon (city site 671 -1090 in this seed,
# reserve to ~380 blocks: the gate forms 18-30 blocks from 1110 -1090), framed by 'awaken gate frame <dist> <lift>' (the
# camera on the line from the gate toward the city's centre, <lift> over the ground or roof there, facing the pillar):
# about 7 and 12 blocks (looking up, inside the haze), 30, 100, 180 and 250 (over the city's roofs), at noon, dusk and
# night, at street level and over roofs.
# Run on GitHub's Mac runners:
#   tools/tour-ci.sh tools/autopilot/pillars.txt 1800 TECTONIC=awakened PACK=perf,world,horizon LENS=cinematic
# (Cinematic: Lens 2's clouds behind the pillar, where the slab showed as a hole in them)
world carillonM4b3a creative 20261024
waitworld
gui 0
cmd gamerule send_command_feedback false
cmd gamerule spawn_mobs false
cmd gamerule advance_time false
cmd weather clear 1000000
cmd awaken admin awaken
wait 200
cmd awaken powers starter 1
wait 20
screen close
window 1440 900
info
hud off
cmd gamemode spectator
cmd time set 6000
cmd tp @s 1110 140 -1090
wait 100
# the first that finds ground stands; the others fall within 96 blocks of it and are refused
cmd awaken gate open C
wait 20
cmd awaken gate open C
wait 20
cmd awaken gate open C
wait 200
cmd awaken gate list

cmd awaken gate frame 30 0
wait 200
