# Pixels' decisive measurement (SPEC §16, docs/perf/pixels/REPORT.md). In each scene every scaled setting is measured
# between two native windows (native, 0.75 sharp, native, 0.67 sharp, native, 0.67 FSR, native, 0.67 bilinear, native,
# 0.5 sharp, native, 0.5 FSR, native), so the drift of a world still loading at RD 32 and of a busy machine cancels:
# tools/pixels-report.py compares each with the mean of its two neighbours. Each window logs frame times ('perf') and
# the GPU time of the world pass and of the upscale ('[pixels] gpu', timestamp queries). Then a shot at each setting.

# screen, shots only.
# Run: SLOT_WHO=pixels PACK=perf RD=32 slot.sh tour tools/autopilot.sh tools/autopilot/pixels.txt
