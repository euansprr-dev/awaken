# Full-body cast clips (Player Animation Library, optional): one power or more per family, the camera behind the
# caster and then facing it. Shots land about 6-7 ticks into a clip (the follow-through) and again near its end.
# Run it twice: PACK=feel tools/autopilot.sh tools/autopilot/powers-fx-body.txt (the clips) and plain (vanilla poses).
world powerfx creative 4242
waitworld
gui 0
cmd gamerule awaken:fauna_spawning false
cmd gamerule send_command_feedback false
cmd gamerule spawn_mobs false
cmd weather clear 100000
cmd time set 6000
cmd awaken admin awaken
wait 200
cmd awaken powers starter 1
wait 20
screen close
cmd tp @s 0.5 200 0.5 0 8
cmd fill -12 199 -8 12 199 22 minecraft:smooth_stone
cmd fill -12 200 -8 12 216 22 minecraft:air
wait 40
