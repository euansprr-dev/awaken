# Power FX studio: every power cast at a standing zombie on a plain sky platform, screenshots of wind-up, release and
# impact/linger (first person; the cast poses are best judged in a second run with F5 pressed by hand). The starter
# powers, Dash and the ultimates are repeated at night to judge the glow. Builders: never run this; the integrator does.
world powerfx creative 4242
waitworld
gui 0
cmd gamerule awaken:fauna_spawning false
cmd gamerule send_command_feedback false
cmd gamerule spawn_mobs false
cmd weather clear 100000
cmd time set 6000
cmd awaken admin awaken
wait 200
cmd awaken powers starter 1
wait 20
screen close
cmd tp @s 0.5 200 0.5 0 8
cmd fill -12 199 -8 12 199 22 minecraft:smooth_stone
cmd fill -12 200 -8 12 216 22 minecraft:air
wait 40
