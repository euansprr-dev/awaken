# Structures tour (docs/modules/structures.md): the gate vortex at every rank and in every look, the Well, the four
# ruin kinds and the nine lairs, each from afar and up close, by day and by night.
# Run by the integrator: tools/autopilot.sh structures (builders never run a client).
#
# Commands it relies on (game master):
#   /awaken gate showcase <E|D|C|B|A|S|SOVEREIGN> <open|warning|broken|calm|spent|forming> [red]   a display gate ahead
#   /awaken gate showcase clear                                                                    removes them (96 blocks)
#   /awaken above ruin showcase <vault|spawn_vault|monolith|ocean_lab|sky_platform>                 a ruin ahead, door toward you
#   /awaken landmark goto <well|vault|monolith|ocean_lab|sky_platform>   48 blocks south of the nearest real one, facing it
#   /awaken fauna lair place <beast>                                     a lair 16 blocks ahead
# Moving to fresh ground between builds: spreadplayers drops you on the surface 90 blocks east.
