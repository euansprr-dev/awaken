# The Wilds, first part (SPEC §17): a Precursor ward taking back a placed block (the mark, then the crumble: grains in
# the block's colour, the Signal's light rising), a vault wall that holds, and the Horizon line under the Now tracker
# (a vault to walk to, then a sky platform's tease). `/awaken wilds place` and `strike` act as a survival player would;
# `/awaken wilds why` prints the ward, the last 20 s of movement and the Horizon line. A light tour (screenshots only).
world wilds creative 7311
waitworld
gui 0
cmd awaken admin awaken
wait 60
screen close
cmd awaken powers starter 1

cmd time set 6000
cmd time pause

# ---- the Horizon line ----
# level 4+: a sealed vault is worth the walk (before reaching it, which takes it off the line)
